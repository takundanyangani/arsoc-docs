## Appendix A: Glossary of Terms

| **Term** | **Definition** |
|---|---|
| Batch | Group of inventory items purchased together from a supplier |
| Serial Number | Unique identifier assigned to each individual item for tracking through sales lifecycle |
| Partner | Financial institution (bank) providing credit and loan services |
| Installment | Payment plan term (e.g., 2 months, 6 months, 12 months) for credit purchases |
| Disbursement | Process of transferring approved loan funds to customer's bank account |
| Approval Queue | List of pending applications awaiting sales team review and decision |
| Model | Specific product variant (e.g., Samsung S23 Ultra is a model) |
| Pricing List | Table of product models and their loan amounts per partner and currency |
| Commission | Payment to agent based on successful loan closures and sales performance |

## Appendix B: System Requirements

### Browser Requirements (Web Interface)

- Chrome 90+, Firefox 88+, Safari 14+, or Edge 90+
- JavaScript enabled
- Cookies enabled

### Mobile & WhatsApp Requirements

- WhatsApp installed on iOS or Android device
- Internet connection (3G, 4G, or WiFi)
- Basic messaging familiarity

### Document & File Requirements

- Supporting documents: PDF, JPG, PNG formats
- Pricing lists: Excel (.xlsx) format
- File size limits: 5 MB per file

## Appendix C: Quick Reference Guide

### Common Tasks

| **Task** | **Who Does This** | **Menu Path** |
|---|---|---|
| Create new batch | Stock Manager | Stock > Batches |
| Approve pending batch | Operations Manager | Stock > Batches |
| View agent inventory | Stock Manager | Stock > Agents |
| Review pending loan applications | Sales Officer | Loan > Approval Queue |
| Process loan disbursement | Finance Officer | Loan > Disbursement |
| Submit client application | Field Agent | WhatsApp: Create App |
| Manage user accounts | System Admin | Admin > Users |
| Configure system settings | System Admin | Admin > Settings |

### Quick Navigation

**For Stock Managers:**
- Stock > Batches → Create and manage inventory
- Stock > Agents → View and manage agent assignments
- Stock > Transfer Stock → Record stock exchanges between agents
- Stock > Returned Stock → Process customer or agent returns

**For Sales Officers:**
- Loan > Clients → Maintain customer records
- Loan > Partners → Manage bank partnerships
- Loan > Approval Queue → Review pending applications
- Loan > Disbursement Queue → Process approved loans
- Loan > Pricing List → Upload product pricing by partner and currency

**For System Administrators:**
- Admin > Users → Create and manage user accounts
- Admin > Branches → Configure branch structure
- Admin > Modules → Enable/disable system modules
- Admin > Settings → Configure global system settings

**For Field Agents:**
- WhatsApp > Create Application → Submit new customer applications
- WhatsApp > Check Status → Review application status
- WhatsApp > My Applications → View application history
