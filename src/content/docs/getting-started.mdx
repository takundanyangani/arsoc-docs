## How to Use This Documentation

Welcome to the ALPHA System documentation. This guide is organized by role and function to help you find what you need quickly.

**If you're new to ALPHA**, start with the [System Overview](/overview/) to understand the big picture.

**If you know what you need**, use the topic groups below to jump directly to the relevant section.

:::tip
Use the search function (Ctrl+K or Cmd+K) to find specific topics quickly across all documentation.
:::
